# 阶段 3 · 剧本

**写的是说出来的话，不是读出来的文章。** 判据只有一条：念一遍，卡不卡。

## 开工前

读 `$VFLOW/profile.md`，读 `02-outline.md`。框架不存在就先回 `vflow-outline`。

## 写作规则

1. **短句。** 一句不超过 20 字，超过就断。
2. **一页一到两句。** 框架里一页 45–55 字，不是 45–55 字的一段话。
3. **口语，不是书面语。** "所以""其实""你看""说白了"这类连接词是口播的骨架，别嫌啰嗦删掉。
4. **先结论后解释。** 每页第一句给结论。
5. **数字和专有名词要念得顺。** "2026 年 10 月"比"2026.10"好念；英文缩写第一次出现要给中文全称。
6. **不写书面语排比。** 三个"因为"排下来，念着像演讲，观众会出戏。
7. **留白。** 转折前、金句后标 `[停顿]`，长句中间标换气点。

## 语气

照 profile 里的语气设定走。默认基线：

- 说人话，不用"赋能/抓手/底层逻辑/闭环/颗粒度"这类词
- 可以吐槽，可以承认翻车，但要具体到哪一步翻的
- 不喊口号，不贩卖焦虑
- 一句话能说完的不用三句

## 写完之后：跑一遍流畅度自检

逐段过这五项，标出问题的具体位置：

| 检查项 | 看什么 |
|---|---|
| **衔接** | 上一页最后一句和这一页第一句之间有没有逻辑缺口。缺了就补半句过渡，不要让观众自己猜 |
| **信息密度** | 连续三页以上都是"讲道理"没有具体例子/数字/画面 → 观众会走。在第三页前插一个具体东西 |
| **流失点** | 每页开头如果是"接下来""然后""第二"这类纯过渡词，改成直接给内容 —— 过渡词是划走高发区 |
| **重复** | 同一个意思换个说法说了两遍 → 删一遍 |
| **念着卡** | 通读一遍，标出所有念不顺的地方，改到顺 |

## 真人出镜时的补充

走真人路线的话，另写 `03b-teleprompter.md` 提词稿：

- 字号要大，一行不超过 12 字
- 标注每段预计秒数、换气点、重录提示
- **真人录音是主时钟**，字幕按实际音频对齐，别按稿子估时间

## 收尾

自检五项全过，再进 `vflow-package`。

稿子没改顺就往下走，制作阶段会付出三倍代价——因为要重录、重渲染、重对时间轴。
