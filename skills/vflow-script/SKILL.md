# 阶段 3 · 剧本

**写的是说出来的话，不是读出来的文章。** 判据只有一条：念一遍，卡不卡。
但卡不卡只是底线，留不留人靠结构。

## 开工前

读 `$VFLOW/profile.md`，读 `02-outline.md`。框架不存在就先回 `vflow-outline`。

**再读两个库和一个档案**，别跳过：

- `$VFLOW/assets/structures.md` —— 六个结构模板。**这一步先选模板，不要开始造句。**
- `$VFLOW/assets/hooks.md` —— 十二类钩子原型。开头从这里挑，至少写 3 个不同原型的变体。
- `python3 $VFLOW/scripts/voice_profile.py show` —— 你自己的实测文风数字。

**照数字写，不要照规则写。** profile 里"说人话、先给结论"是规则，模型照规则写还是像 AI；
风格卡里的句长、语气标记频率是实测，照着对齐才像你。

## 第一步：选结构模板

不要临场发明结构。从 `structures.md` 里选一个：

| 你手里有什么 | 选 |
|---|---|
| 一个推翻常识的判断 | T1 重新定义题 |
| 一个能解释很多现象的结论 | T2 判断先行 |
| 一套可复用的做法 | T3 拆解三步 |
| 我自己真做过的一次实验 | T4 自证实验 |
| 两个方案要选一个 | T5 对比评测 |
| 一份能让观众少踩坑的清单 | T6 清单避坑 |

一条只用一个模板。混用会表现成"前 30 秒像 T1、后面变成 T3"，观众会感到结构塌了。

## 第二步：定可保存物（硬门槛）

2026 年平台权重在往"收藏、复访"走，可保存物从加分项变成了入场券。按内容类型分档：

| 类型 | 必须带走 | 没有就 |
|---|---|---|
| **B 拆解型** | 一条判断标准 / 一张对照表 / 一个决策树 | 不许进制作 |
| **A 演示型** | 一个能照做的步骤 / 一组参数 / 一个可复用文件 | 不许进制作 |
| **C 实录型** | 一个判断或一个动作 | 可以只给一个，但不能没有 |

在稿件头写清楚：**是什么，第几秒出现。** 写不出来就是还没想清楚，回结构阶段。

## 第三步：写三个钩子变体

不要只给一个。至少 3 个**不同原型**，让使用者挑。

| 要求 | 说明 |
|---|---|
| 2 秒内念完 | 超过就砍。念一遍，不要在心里读 |
| 口播 + 画面分工 | 口播说"为什么听"，画面给"看什么"，不要重复 |
| 价值前置 | 5 秒留存优先，悬念式开头（"最后一条最重要"）两头都拿不到 |
| 承诺可兑现 | 钩子承诺的，正文第一段就开始给 |

## 第四步：排留存曲线

**宏观**：四个大刺激点，大约在全片的 0% / 25% / 50% / 75%。

| 位置 | 作用 |
|---|---|
| 0% | 钩子——为什么现在看 |
| 25% | 第一个实打实的证据或结果 |
| 50% | 机制 / 方法的核心——为什么成立（中段 re-hook 放在这附近） |
| 75% | 更大的后果 / 第二重证据 / 情绪转折 |
| 结尾 | 承诺兑现 + 一个动作 |

**微观**：每 8–15 秒要有一个变化——新问题、新画面、新数字、一个反转、一句短判断。
连续两段只有抽象论述，就是流失点。

**能量不能一直满。** 密集信息之后给一个低能量拍（一句短的、停顿、画面静止），
大刺激才显得大。全程高能观众会累，反而留不住。

## 第五步：双轨写两版

同一条内容，抖音和小红书要两个版本。**不是把短的拉长，是换一种给法。**

| 轨道 | 平台 | 时长 | 节拍密度 | 靠什么留人 |
|---|---|---|---|---|
| 发现轨 | 抖音 | 45–90 秒 | 每 8–12 秒一个点 | 判断前置，前 3 秒定生死 |
| 深度轨 | 小红书 | 90–180 秒 | 每 15–20 秒一个点 | 步骤完整，能照着做，搜索词铺满 |

两个版本共用同一个核心判断和同一个可保存物，但开头、例子密度、结尾动作都要重写。
只做一端可以，但要在稿件头写明。

## 写作规则

1. **短句。** 一句不超过 20 字，超过就断。
2. **一页一到两句。** 一页 45–55 字，不是一段话。
3. **口语，不是书面语。** "所以""其实""你看""说白了"是口播的骨架，别嫌啰嗦删掉。
4. **先结论后解释。** 每页第一句给结论。
5. **数字和专有名词要念得顺。** "2026 年 10 月"比"2026.10"好念；英文缩写第一次出现要给中文全称。
6. **不写书面语排比。** 三个"因为"排下来，念着像演讲。
7. **留白。** 转折前、金句后标 `[停顿]`，长句中间标换气点。
8. **口播和画面分工。** 画面已经给了的信息，口播不要再念一遍。

## 语气

照 profile 走。默认基线：说人话；可以吐槽、可以承认翻车，但要具体到哪一步；
不喊口号、不贩卖焦虑；一句话能说完的不用三句。

## 写完之后：四项检查，一个都不能省

### 1. 留存五项

| 检查项 | 看什么 |
|---|---|
| **钩子强度** | 前 2 句有没有判断 / 冲突 / 数字。有"大家好 / 今天 / 我想说"就是 FAIL |
| **价值前置** | 前 1/3 有没有交付可保存物。全片最后才给，前 5 秒没东西可拿 |
| **留存曲线** | 四个大点都在吗；有没有连续 15 秒以上只有抽象论述 |
| **承诺兑现** | 钩子承诺的东西，正文真的给了吗 |
| **可保存性** | 有没有一个能截图 / 收藏的东西 |

### 2. 流畅度五项

衔接（页间有没有逻辑缺口）、信息密度（连续三页讲理没具体东西）、
流失点（页首是"接下来/然后"这类过渡词）、重复（同一个意思说两遍）、念着卡（真念一遍）。

### 3. 机器自检

```bash
python3 $VFLOW/scripts/script_check.py projects/<slug>
```

按轨道阈值自动查：慢热开头、缺开放循环、缺 re-hook、前 1/3 无可保存物、
CTA 指向点赞、句长 / 语速 / 时长偏差、AI 味、金句密度、重复、钩子变体不足。

**FAIL 必须改，WARN 自己判断。** 结果写进 `03-script.md`，不要拿旧报告当真。

### 4. 声音档案比对

```bash
python3 $VFLOW/scripts/voice_profile.py compare projects/<slug>/03-script.md
```

列出偏离项（句长、第一人称密度、你从不用词）和禁用词命中。偏离的改到范围内再往下走。

## 产出：`03-script.md`

结构见 `pipeline/03-script.md`。核心是这几块：稿件头（模板 / 判断 / 可保存物 / 开放循环 /
re-hook / 结尾动作）、钩子三变体、双轨版本、分镜表、逐字稿、留存自检、掐表、五项自检、机器自检。

**分镜表是给制作阶段用的**，时间列必须能和逐字稿对上。

## 真人出镜时的补充

另写 `03b-teleprompter.md` 提词稿（骨架见 `skills/_shared/teleprompter-template.md`）：
字号要大、一行 ≤12 字、标每段预计秒数 / 换气点 / 重录提示。
**真人录音是主时钟**，字幕按实际音频对齐，别按稿子估时间。

## 边界

**做**：选模板、定可保存物、写钩子变体和双轨口播稿，产出 `03-script.md`。

**不做**：不改结构（要加页、调顺序、换模板，回 `02-outline.md`）；不查敏感词和平台风险（那是检查）；
不定标题封面（那是包装）。图文正文和公众号文章不是口播稿，别用这里写。

**单独被调用时**：`02-outline.md` 不存在就说明并回 `vflow-outline`；声音档案不存在就先放 2–3 篇
**你自己写过**的成稿进 `assets/voice-samples/`，跑 `voice_profile.py build`。

**越界信号**：念着卡是因为结构本身有问题，改句子解决不了——回结构。
想给 5 个钩子让使用者挑，但 5 个都是同一个原型——这不是变体，是改写。

## 收尾

留存五项 + 流畅度五项 + 机器自检全过，再进 `vflow-package`。

稿子没改顺就往下走，制作阶段会付出三倍代价——要重录、重渲染、重对时间轴。
