# 阶段 4 · 包装

三件套：**文字标题**（发布时挂的）、**封面标题**（压在画面上的大字）、**开头 3 秒**（口播或冷开场画面）。

三者各干各的活，不要写成一句话的三种说法。

## 开工前

读 `$VFLOW/profile.md`，读 `03-script.md`。

## 文字标题

抖音和小红书必须分开写：

| | 抖音 | 小红书 |
|---|---|---|
| 长度 | ≤20 字 | ≤20 字（**前 20 字必须含核心关键词**） |
| 风格 | 口语、带冲突、带具体数字 | 可带 emoji、铺搜索词、给答案感 |
| 目的 | 让人停 | 让人搜得到、点得开 |

写法，按优先级：

1. **结果前置**：做完这件事得到什么
2. **反常识**：大家都以为 X，其实 Y
3. **具体痛点**：把观众心里那句话原样说出来
4. **数字**：具体数量比形容词有力

**避免**：空泛的"XX 干货"、问句当标题（除非问题本身就是观众的原话）、标题党到正文兑现不了。

一个选题出 3–5 个候选，让使用者挑。

## 小红书：关键词矩阵（必做）

小红书的流量命脉是搜索。2026 年搜索算法是**语义理解**，堆词会被判低质——
要回答观众真正在问的问题。每条笔记必须填满四个维度：

| 维度 | 数量 | 放哪 | 例 |
|---|---|---|---|
| **核心词** | 1–2 个 | 标题前 20 字 | AI 工具 / 企业 AI |
| **长尾词** | 2–3 个 | 标题后半 + 正文前 3 段 | 小团队怎么选 AI 办公平台 |
| **问题词** | 1–2 个 | 标题问句 / 正文首段 | 换 AI 工具要重讲业务吗 |
| **场景词** | 2–3 个 | 正文例子 + 标签 | 写周报 / 整理会议纪要 |

**长尾决策词 > 大词**：「10 人团队 AI 周报怎么写」比「AI 办公」竞争小、转化高。
用人群 + 场景 + 痛点的组合，不用行业大词。

**正文**：前 3 段自然出现关键词，中间融衍生词，结尾给行动词。标签 5–10 个，
混核心词 + 场景词 + 账号词。**不要把关键词堆在同一句里。**

**标签**：抖音 3–5 个话题；小红书 5–10 个，优先"别人会搜的"，不是"你希望被归类的"。

## 封面标题

画面上的大字，规则不一样：

- **字数更少**：≤12 字，手机上要一眼读完
- **和文字标题不重复**：文字标题负责悬念，封面标题负责说清这片子讲什么
- **大字压屏**：抖音尤其，字要占到画面宽度的 70% 以上
- **小红书要美**：精致度直接影响点击，别只堆字

## 开头 3 秒：从钩子库里挑，别现场编

```bash
python3 scripts/hooks.py list     # 看九类钩子
python3 scripts/hooks.py best     # 按你的历史数据排序，推荐该用哪个
```

`assets/hooks.md` 里九类钩子各有模板、机制和适用类型。**先挑再改，不要凭空想。**

用了哪个必须记下来，否则数据攒不起来：

```bash
python3 scripts/hooks.py use H7 20261022-你的项目 --platform douyin
```

复盘阶段再回填数据（`hooks.py fill`）。攒够之后 `best` 会告诉你哪类钩子对你真的有效——**一条数据不算数**。

短视频的生死线。三种最常用的开头：

| 类型 | 结构 | 适用 |
|---|---|---|
| **冷开场** | 画面先给结果/翻车/对比，再说主题 | 演示型 |
| **反常识断言** | 第一句就是一个反直觉判断 | 拆解型 |
| **痛点原话** | 把观众心里那句话直接说出来 | 通用 |

**不要**：自我介绍、大家好、今天我们来聊聊。前 3 秒说这些等于自杀。

## 兑现检查（必做）

包装写完之后，回到正文逐条核对：

- 标题承诺的东西，正文真的给了吗？
- 开头抛的问题，后面回答了吗？
- 封面字和口播内容对得上吗？

承诺兑现不了，改标题，不要改正文去硬凑——硬凑出来的内容观众能感觉到。

## 封面要过机器检查

封面字写完，先跑一遍，别等成片出来才发现手机上读不完：

```bash
python3 $VFLOW/scripts/qc.py cover <slug>
```

它查四件事：字数超没超、封面字和标题是不是一模一样（浪费信息位）、
有没有广告法极限词、按 13% 字高排版会不会折成三行以上。默认还会生成
`output/qc/cover-douyin.png` 和 1080 宽的手机缩略图，**打开缩略图看一眼**——
信息流里就是那么大，全尺寸好看不算数。

没有现成封面图时，用 `python3 $VFLOW/scripts/qc.py template` 生成两张底图
（9:16 和 3:4），在底图上排字，安全区已经画好。

## 发布前包检查

包装写完跑一遍：

```bash
python3 $VFLOW/scripts/qc.py package <slug>
```

查：双平台标题长度、小红书前 20 字有没有核心词、标签数量、关键词矩阵四维是否填满、
AI 生成声明、有没有留联系方式。**有 FAIL 不许进制作。**

## 边界

**做**：出文字标题、封面标题、开头 3 秒三件套，按平台各写一版，并检查正文有没有兑现开头承诺。

**不做**：不改稿子内容——承诺兑现不了时，要改的是 `03-script.md`（甚至 `02-outline.md`），不是把标题写软；不生成封面图片；不写发布文案（那是制作阶段的 `publish-copy.md`）。

**单独被调用时**：`03-script.md` 不存在就说明并回 `vflow-script`。角度还没定、需要先开发并确认主线时，先把主线定下来再回来包装——角度没定时硬写三件套，等于把没想清楚的东西包装得更漂亮。

**越界信号**：还在纠结"这条到底讲什么"——那是选题或结构的问题，回前面。

Vflow 不依赖任何外部工具，没装也能跑完整条流水线。

## 收尾

进 `vflow-check`。包装没过检查不许进制作——标题改一次很便宜，成片重做很贵。
