# 阶段 7 · 复盘

**目的不是打分，是找出下一条能改的具体动作。** 写不出动作的复盘等于没写。

## 什么时候做

发布 **48 小时后**。太早数据没跑完，太晚记忆凉了。

## 看数据先分桶

不同受众的内容不能横向比。按 profile 里的定位先分桶，桶内比：

- **专业向**（面向决策层、客户）：看涨粉质量、私信/咨询、完播。播放量本来就不会高
- **泛流量向**（面向普通观众）：看播放、5 秒完播、互动率

**跨桶比数据会得出错误结论。** 一条专业向内容播放 3000 但来了 2 个咨询，比泛流量 10 万播放有用。

## 四个必看指标

| 指标 | 说明什么 | 低了改哪里 |
|---|---|---|
| **5 秒完播** | 开头钩子 | 回头改 `04-package.md` 的开头 3 秒 |
| **整体完播** | 结构和节奏 | 回头看 `02-outline.md`，通常是有页废话或方法页太多 |
| **互动率**（赞/评/藏） | 有没有共鸣和增量 | 回头看 `03-script.md`，通常是没有具体一手经验 |
| **涨粉** | 值不值得关注这个人 | 看 profile 的人设一致性，以及有没有给出"下一条还想看"的理由 |

小红书额外看**搜索来源占比**——占比高说明关键词铺对了，这条会长尾。

## 归因要具体到步骤

不要写"内容不够好"。写清楚是哪一步出的：

- 选题阶段：三问里哪一问其实没过但硬做了
- 结构阶段：转折点来得太晚 / 方法页超过 4 页 / 缺证据页
- 剧本阶段：念着卡 / 信息密度不均 / 没有一手经验
- 包装阶段：标题承诺与正文不符 / 开头 3 秒是自嗨
- 检查阶段：被限流了（看是不是机器风险没清干净）

## 写回 profile：得过台账这一关

**一条数据不是规律。** 完播高可能是选题好、可能是钩子好、也可能只是运气。所以观察不直接进 profile，先记进证据台账：

```bash
python3 scripts/ledger.py add "露脸开头的完播明显高" --slug 20261022-这条
# 下次又见到同样现象：
python3 scripts/ledger.py add x --slug 20261025-下一条 --again E1
# 攒够三条再升级：
python3 scripts/ledger.py promote E1
```

三条门槛：

1. 一条 = 候选，**不改任何默认**
2. 三条**可比**证据（同平台、同类型、同期）才能升级
3. 升级必须可逆——脚本会告诉你改了什么、因为哪几条、怎么撤回。出现反例就 `retract` 降级

不够三条时 `promote` 会**直接拒绝**，并告诉你还差几条。这不是啰嗦，是防止"一条爆了就改方法、下一条照抄就扑了"这个最常见的坑。

只有升级之后的结论才写进 profile.md 第 8 节积累区。写的时候越具体越有用：

- ❌ "讲 AI 的内容数据好"
- ✅ "开头给具体数字（不是'很多'）的拆解型内容，5 秒完播平均高 12 个点"

**钩子数据也要回填**，否则钩子库永远是空的：

```bash
python3 scripts/hooks.py fill H7 20261022-这条 --ret3 48 --finish 31 --verdict 有效
```
