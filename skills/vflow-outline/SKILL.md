# 阶段 2 · 结构

**剧本写崩，九成是结构阶段没想清楚。** 这一步不写句子，只排点。

## 开工前

读 `$VFLOW/profile.md`、`01-topic.md`、`$VFLOW/assets/structures.md`。
选题卡不存在就先回 `vflow-topic`。

## 第一步：选模板

不要从"第一部分讲背景"开始。先判断这条属于哪个模板：

| 你手里有什么 | 选 | 节拍 |
|---|---|---|
| 一个推翻常识的判断 | T1 重新定义题 | 你以为 → 其实 → 证据 → 新判断 → 动作 |
| 一个能解释很多现象的结论 | T2 判断先行 | 判断 → 三个理由 → 边界 → 落到个人 |
| 一套可复用的做法 | T3 拆解三步 | 现象 → 归因 → 方法 → 证据 → 动作 |
| 我自己真做过的一次实验 | T4 自证实验 | 我做了 X → 过程 → 结果 → 代价 → 结论 |
| 两个方案要选一个 | T5 对比评测 | A vs B → 判据 → 结果 → 谁该选 |
| 一份能少踩坑的清单 | T6 清单避坑 | 预告 → 每条一个证据 → 收口 |

**一条只用一个模板。** 这条写进 `02-outline.md` 的第一行。

## 第二步：算时长，定轨道

| 轨道 | 时长 | 页数 | 每页字数 | 节拍密度 |
|---|---|---|---|---|
| **发现轨（抖音）** | 45–90 秒 | 5–8 页 | 45–55 字 | 每 8–12 秒一个点 |
| **深度轨（小红书）** | 90–180 秒 | 9–14 页 | 45–55 字 | 每 15–20 秒一个点 |

口播速度按 **每秒 4–4.5 字** 估（中文），留呼吸和停顿。超过 180 秒就拆成两条。

双轨都做时，先在结构表里写清两版的差异（开头、例子密度、结尾动作），不要只改时长。

## 第三步：排四个大刺激点

不管哪个模板，这四个位置必须有东西：

| 位置 | 是什么 | 没有会怎样 |
|---|---|---|
| 0% | 钩子：为什么现在看 | 前 5 秒留不住 |
| 25% | 第一个实打实的证据 / 结果 | 观众觉得你在铺垫 |
| 50% | 机制 / 方法核心 + 中段 re-hook | 完播率从这里往下掉 |
| 75% | 更大的后果 / 第二重证据 | 后半段变成重复 |

在页面表里用 **★** 标出来。四个 ★ 缺一个，这张结构表就不合格。

## 第四步：标可保存物

按内容类型定，这是硬门槛：

| 类型 | 可保存物 | 位置要求 |
|---|---|---|
| B 拆解型 | 判断标准 / 对照表 / 决策树 | 前 1/3 必须出现一次，结尾再收一次 |
| A 演示型 | 步骤 / 参数 / 可复用文件 | 前 1/3 露出结果，方法页给完整步骤 |
| C 实录型 | 一个判断或一个动作 | 结尾必须给 |

在页面表里用 **◆** 标出可保存物在哪一页。**没有 ◆ 的结构表不许进剧本阶段。**

## 第五步：填页面表

| 页 | 角色 | 这一页的点 | 留存动作 | 预估秒 |
|---|---|---|---|---|
| 1 | 钩子 | | 判断 / 冲突 / 数字 | 3–5 |
| 2 | 共情 | | 开放循环 | 8–10 |
| 3 | 转折 ★25% | | 第一个证据 / 可保存物 ◆ | 10 |
| ... | 方法 | | | |
| N | 收尾 | | 承诺兑现 + 动作 | 8 |

**角色只用这几个**：钩子、共情、转折、方法、证据、re-hook、收尾。
不要写"背景""总览"这种不知道在干什么的角色。

## 排点的四条规则

1. **一页一个点。** 一页塞两个意思，观众两个都记不住。
2. **先结论再理由。** 每页第一句就是这页的结论。
3. **方法页不超过 4 页。** 超过说明塞了两个选题，拆开。
4. **中段 re-hook 必须接新东西。** 只写"但是更重要"是空转。

## 需要外部支撑时

- 观点要理论背书 → 先确认理论真的成立、真的适用，别硬套名人。找不到就用一手经验。
- 讲一个概念 → 先划清边界，别和相邻概念混着用。

## 边界

**做**：选模板、排页面级结构、标四个大刺激点和可保存物、定双轨差异。只排点，不写句子。

**不做**：不写具体措辞（那是剧本）；不定标题封面开头（那是包装）；不改选题本身——
发现选题有问题就停，回 `01-topic.md` 改。

**单独被调用时**：`01-topic.md` 不存在就说明并回 `vflow-topic`，不要凭空造结构。

**越界信号**：想改的是一句话怎么说——那不是结构问题，去 `vflow-script`。

## 收尾

写完**停一次**，把框架给使用者过目，点头了再进 `vflow-script`。

框架改起来比稿子便宜得多。这一步多改两遍，剧本阶段少返工三遍。
