# 阶段 2 · 结构

**剧本写崩，九成是结构阶段没想清楚。** 这一步不写句子，只排点。

## 开工前

读 `$VFLOW/profile.md`，读 `01-topic.md`。选题卡不存在就先回 `vflow-topic`。

## 时长与页数换算

口播速度按 **每秒 4–4.5 字** 估（中文），留呼吸和停顿：

| 时长 | 页数 | 每页字数 |
|---|---|---|
| 60 秒 | 5–6 页 | 45–55 字 |
| 90 秒 | 8 页 | 45–55 字 |
| 120 秒 | 10–11 页 | 45–55 字 |

短视频别超 120 秒。要讲的超出这个量，拆成两条。

## 每页必须有一个角色

不要写"第一部分讲背景"这种流水账。每页标注它在全片里干什么：

| 角色 | 干什么 | 通常在哪 |
|---|---|---|
| **钩子** | 3 秒内让人停下。反常识 / 具体痛点 / 结果前置 | 第 1 页 |
| **共情** | 证明我知道你卡在哪，别急着给答案 | 第 2 页 |
| **转折** | 给出反直觉的判断——"问题不在 X，在 Y" | 第 3 页 |
| **方法** | 具体怎么做，分步骤 | 第 4–N 页 |
| **证据** | 我做过的、数据、对比 | 穿插 |
| **收尾** | 一句话收口 + 一个动作，不喊口号 | 最后一页 |

**方法页不超过 4 页。** 超过就说明塞了两个选题，拆开。

## 排点的三条规则

1. **一页一个点。** 一页里塞两个意思，观众两个都记不住。
2. **先给结论再给理由。** 每页的第一句就是这页的结论，后面才解释。
3. **转折必须在前 1/4。** 转折点来太晚，前面就变成铺垫，观众已经划走了。

## 需要外部支撑时

- 观点需要理论背书 → 先确认这个理论真的成立、真的适用，别硬套名人。找不到就用自己的一手经验当证据，比硬套理论强。
- 讲一个概念 → 先把概念边界划清楚，别和相邻概念混着用。
