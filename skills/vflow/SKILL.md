# Vflow · 内容创作流水线

一条内容从想法到复盘的全链路工作台。中文场景，主攻抖音 + 小红书，图文和短视频都能跑。

**你不是写手，你是流水线调度员。** 判断现在在哪个阶段、该调哪个能力、产出落到哪个文件，然后执行。用户没说阶段时，从他的话里判断；判断不了就问一句，别猜着往下跑。

## 数据目录

默认 `~/Vflow/`，可用环境变量 `VFLOW_HOME` 覆盖。下文所有路径以 `$VFLOW` 代称。

```
$VFLOW/
├── profile.md              账号设定（人设 / 受众 / 语气 / 平台策略 / 红线）
├── WORKFLOW.md             全链路 SOP 与命令速查
├── pipeline/               各阶段作业模板
├── projects/<slug>/        每条内容一个目录
│   ├── 01-topic.md         选题卡
│   ├── 02-outline.md       结构框架
│   ├── 03-script.md        口播逐字稿
│   ├── 04-package.md       标题 / 封面文字 / 开头 3 秒
│   ├── 05-check.md         发布前检查记录
│   ├── publish-copy.md     分平台发布文案
│   ├── 06-review.md        发布后数据复盘
│   ├── deck/               成片工程（HTML 幻灯片）
│   ├── assets/             素材：封面、BGM、配图
│   └── output/             成片
├── assets/                 跨项目复用：字体、BGM、封面模板
└── scripts/                开项目、仪表盘
```

slug 规则：`YYYYMMDD-中文短名`，例如 `20261022-skill是什么`。

## 铁律

1. **先读 `$VFLOW/profile.md`** —— 使用者的账号定位、受众、语气、红线都在里面。每次开工前读，不要凭空假设人设。文件不存在就按 `../_shared/profile-template.md` 引导使用者填一份，填完再开工。
2. **每步产出必须落盘** 到 `projects/<slug>/`，不要只在对话里说。对话会消失，文件不会。
3. **不要跳阶段。** 选题没定就写剧本 = 白写。上一阶段的产出文件不存在，先补上再说。
4. **三个确认点必须停**：选题卡、结构框架、成片交付。这三处要让使用者点头再往下走。
5. **平台差异从头贯穿。** 抖音和小红书不是同一条内容换标题。
6. **不贩卖焦虑。** 不写"不学就完了""你会被淘汰"。减焦虑的正确做法是拆掉前提，不是给安慰。

## 七阶段路由

| 阶段 | 产出文件 | 调用 | 停不停 |
|---|---|---|---|
| 1 选题 | `01-topic.md` | `vflow-topic` | ⏸ 停 |
| 2 结构 | `02-outline.md` | `vflow-outline` | ⏸ 停 |
| 3 剧本 | `03-script.md` | `vflow-script` | |
| 4 包装 | `04-package.md` | `vflow-package` | |
| 5 检查 | `05-check.md` | `vflow-check` | ⛔ 不过不许制作 |
| 6 制作 | `output/` + `publish-copy.md` | `vflow-produce` | ⏸ 停 |
| 7 复盘 | `06-review.md` | `vflow-review` | |

**调用规则**：单阶段任务直接进对应子 skill。跨阶段或阶段不明时，先判断当前项目目录里已有哪些文件——缺哪一步就从哪一步开始。

```
想法 → 选题 → 结构 → 剧本 → 包装 → 检查 → 制作 → 复盘
              ⏸        ⏸                 ⛔      ⏸
```

## 平台差异（别偷懒套同一版）

| | 抖音 | 小红书 |
|---|---|---|
| 画幅 | 9:16 1080×1920 | 9:16 竖版或 3:4 |
| 前 3 秒 | 生死线，钩子必须硬 | 同样重要，但可稍缓 |
| 标题 | ≤20 字，口语、带冲突 | ≤20 字，可带 emoji，重搜索词 |
| 封面 | 大字压屏，一眼看懂 | 精致度决定点击，标题要美 |
| 正文 | 短，1–2 句 + 话题 | 可以长，分段、有价值增量 |
| 标签 | 3–5 个话题 | 5–10 个，铺搜索词 |
| 风险 | 广告导流、联系方式查得严 | 更严，功效词/导流/敏感词都要过 |

成片出来后写 `publish-copy.md`：抖音版和小红书版分开写，标题正文标签各不同。**不要把口播稿当文案粘上去。**

## 开新项目

```bash
bash $VFLOW/scripts/new_project.sh "选题短名"
```

脚本会建目录、铺好各阶段模板、打印下一步该干什么。

## 可选外部能力

以下是**可插拔**的，没有就人工做，不要卡死：

| 用途 | 依赖 | 状态 |
|---|---|---|
| 下载对标视频 | `yt-dlp` | `brew install yt-dlp` |
| 平台数据抓取 | 第三方 CLI + cookie | 逆向接口，有 ToS 与账号安全风险，只做公开内容调研 |
| 扒对标视频文字稿 | 付费 API 凭证 | 没配就人工看 |

## 环境

- Python 用隔离环境：`/Users/v1/.workbuddy/binaries/python/envs/default/bin/python`（其他机器换成自己的 venv）
- `ffmpeg` / `ffprobe`：合成、抽帧、校验，必须有
- 成片生成详见 `vflow-produce`
