### 出镜方式怎么选（可删）

| 内容类型 | 形式 | 为什么 |
|---|---|---|
| A 演示型 | 录屏为主，开头可露脸 3 秒钩子 | 演示过程画面是主角 |
| B 拆解型 | 露脸口播，中间插录屏 / 图示 | 讲观点需要人在场 |
| C 实录型 | 露脸 | 记录自己在做什么 |

通用原则：
- **露脸 ≠ 全程对着镜头。** 开头露脸 3 秒钩子 + 主体转录屏，成本最低、效果最稳
- 不露脸的内容也要有"我"在场：旁白用第一人称，讲真做过的事
- 两种形式保持同一个人的语气。观众认的是人，不是脸
