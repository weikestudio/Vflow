# 阶段 5 · 检查

**没过检查不许进制作。** 标题改一次很便宜，成片重做很贵。

两层都要过：**机器会不会误判** + **内容本身有没有问题**。只查一层等于没查。

## 开工前

读 `$VFLOW/profile.md`，读 `03-script.md` 和 `04-package.md`。

然后**先跑词表扫描**，让机器兜第一道底，别只靠眼睛：

```bash
python3 $VFLOW/scripts/risk_scan.py projects/<slug>/
```

输出按严重度排：**红线 > 广告法 > 平台敏感 > 你自己踩过的**。每一条都带文件名和行号，直接能定位。

两个原则：

- 命中**不等于**违规，只等于"值得再看一眼"。平台规则一直在变，词表穷举不完，模型判断在后面接着
- 真踩到坑了，把那个词加进 `assets/wordlist.md` 的 `mine` 层，并写清楚后果。这是词表里唯一别人抄不走的部分

## 第一层：机器会识别什么

逐句检查标题、正文、封面文字、字幕、口播、话题标签、账号资料：

| 风险类型 | 例子 | 处理 |
|---|---|---|
| **绝对化用语** | 最、第一、唯一、100%、彻底、永久 | 换成可验证的具体表述 |
| **功效/效果承诺** | 治愈、根治、 guaranteed、月入 X 万 | 直接删。小红书尤其严 |
| **导流与联系方式** | 微信、加我、私信、二维码、外链 | 抖音和小红书都查，别放 |
| **医疗健康** | 症状、药品、疗效 | 不碰。profile 红线里已禁止 |
| **投资理财** | 收益、稳赚、推荐标的 | 不碰 |
| **时政与敏感事件** | | 不碰 |
| **平台名/竞品名堆砌** | 标题里塞多个平台名 | 减少，容易被判导流 |
| **极限词** | 国家级、顶级、极致 | 删 |

**规则会变，别背清单。** 判断原则是：这句话如果被人举报，平台有没有理由处理我。

## 第二层：内容本身有没有问题

| 检查项 | 问什么 |
|---|---|
| **事实** | 提到的数字、数据、功能、版本，核实过吗？ |
| **承诺** | 标题和开头承诺的东西，正文兑现了吗？ |
| **误导** | 有没有为了让内容好看而省略关键前提？ |
| **焦虑** | 有没有用"不学就完了""你会被淘汰"这类句式？改成拆掉前提，不是给安慰 |
| **免费边界** | 推荐的工具说清免费到哪一步了吗？哪部分要钱？ |
| **贬低他人** | 有没有点名贬低具体同行？ |
| **人设一致** | 这条的语气和 profile 一致吗？有没有突然变成老师腔 |

## 第三层：AI 味检测

机器化表达既招平台限流，也让观众出戏。逐句扫这些特征：

| 特征 | 表现 | 改法 |
|---|---|---|
| **三段式排比** | "不是…而是…""不仅…更…"连用 | 拆掉，只留一句 |
| **对仗工整** | 前后两句字数一样、结构对称 | 打散，口语本来就参差不齐 |
| **总结癖** | 每段后面跟一句总结 | 删。观众自己会总结 |
| **空洞形容词** | 赋能、抓手、深度、全方位、里程碑 | 换成具体名词和动词 |
| **连接词滥用** | 首先/其次/最后/综上所述 | 删掉，直接说 |
| **没有"我"** | 通篇客观陈述，没有第一人称经验和判断 | 加一手经验，说哪一步翻的车 |
| **问句开场** | "你是否曾经…" | 改成陈述句断言 |
| **同一个意思说两遍** | 换个词重复一遍显得"有层次" | 删一遍 |

**判据**：念一遍，像不像一个真人在说话。不像就改。

## 视频语境边界：贴片小字

如果内容里有演示画面、数据截图、第三方界面，容易被误读为真实承诺或官方信息，在画面上加**三行贴片小字**：

```
（第一行）这是什么：演示环境 / 示例数据 / 第三方界面
（第二行）真实边界：实际结果因 X 而异
（第三行）时间：录制于 YYYY-MM
```

三行必须真实准确，不写免责套话。

## 边界

**做**：三层闸口——平台机器会识别什么、内容本身有没有问题、AI 味。够用即过，每条都过，产出 `05-check.md`。

**不做**：不直接改写内容，只标位置和最小修改动作（改是上游阶段的事）；不做逐句全量深检。高风险内容要覆盖图片文字、字幕、评论、账号资料、视频画面时，用你环境里更细的风险检测能力再跑一遍——可选，不是必须。

**单独被调用时**：`03-script.md` 或 `04-package.md` 不存在就先补齐。结构都还没定的草稿拿来检查，查出来的问题第二天就作废。

**越界信号**：希望检查阶段顺手把稿子改好——不行，改完等于没检查，回到对应阶段改。

Vflow 不依赖任何外部工具，没装也能跑完整条流水线。

## 收尾

三层全过才能进 `vflow-produce`。有遗留问题就在这里改完，**不要带着问题往下走**——制作阶段改一处，字幕、音频、封面全要重来。
