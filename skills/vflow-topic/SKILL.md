# 阶段 1 · 选题

**目的不是想出一个好点子，是尽快否掉不值得做的点子。** 一张选题卡的价值，一半体现在它让哪些想法被毙掉。

## 开工前

读 `$VFLOW/profile.md`。没有就先引导填，别凭空假设人设。

## 第一步：先过三问，不过就毙掉

任何想法进来，先回答（对照 profile 里的受众和主线）：

1. **观众能拿走一个具体动作吗？** 不是"了解""认知"，是能立刻做的一件事。
2. **这条能证明我会做，而不只是会说吗？** 讲过的方法自己跑通过没有。
3. **三个月后还有人搜吗？** 小红书尤其看这条。纯热点选题答不了这题就标注"短期流量"。

有一条答不了，先别急着毙——写明答不了的原因，让使用者决定。但默认建议毙。

## 第二步：找对标（有人做过类似的才做）

**没有对标的内容，等于自己当实验品。** 找 3–5 条同类内容，逐条过三层筛：

| 筛子 | 问什么 | 不过的表现 |
|---|---|---|
| **能学** | 我能看懂它为什么数据好吗？钩子、结构、信息密度分别在哪起作用 | 只看到"他粉丝多"，拆不出机制 |
| **能超** | 我手上有他没有的东西吗？一手经验、更细的步骤、更新的数据、更真的翻车记录 | 只能复述他说过的话 |
| **能持续** | 这条做完了，能长出下一条吗？还是一次性的 | 做完就没了，不成系列 |

三条全过 = 直接做，把对标的机制抄过来。过两条 = 能做，但要改角度。只过一条 = 换选题。

**对标的颗粒度决定模仿质量。** 抄到"他讲了 AI"没用，要抄到"他第 3 秒抛了一个反常识数字，第 8 秒才说主题"。

### 边界：能抄什么，不能抄什么

**能借**：结构、节奏、角度、钩子出现在第几秒、信息怎么排布。

**必须换**：案例、数据、视角、表述。**只换同义词不算二创。**

抄袭和二创之间没有清晰界线，所以抄完要跑一次机器自检：

```bash
python3 scripts/similarity.py <对标原稿> <你的稿子>
```

输出整体相似度和**最像的那几句**（带原文对照）：

| 相似度 | 判定 | 怎么办 |
|---|---|---|
| < 0.30 | 安全 | 借的是结构，句子是你自己的 |
| 0.30–0.50 | 需检查 | 列出的相似句逐句改：换案例、换视角、换表述 |
| > 0.50 | 高风险 | 这是改写级照搬，重写 |

平台判同质化不看你的意图，看文本重合度。这个脚本把"像不像"变成数字，别靠感觉。

### 可选：抓数据

装了 `yt-dlp` 可以下载对标视频存素材；配了平台 API 凭证可以拉播放/评论。没有就人工看 5 条，把观察到的数据记进选题卡，**不要卡在工具上**。

## 第三步：想清楚观众想推进什么

不要问"观众是谁"（人口学标签没用），问**他在什么情境下想往前推一步，卡在哪**：

- 情境：他刚遇到什么，才来搜/刷这个
- 想推进：他想要达成什么进展
- 现在怎么做的：他现在的替代方案是什么，为什么不够
- 选择标准：他凭什么判断这条内容"有用"

把这四个填出来，剧本阶段才知道该说什么、跳过什么。

## 第四步：估一下值不值

按 profile 里的账号阶段估，不要凭感觉：

- **流量价值**：这个话题的搜索量/讨论量在不在，是不是常青
- **信任价值**：这条能不能证明我有能力（对转化客户尤其重要）
- **成本**：查资料、做演示、拍摄分别要多久

**成本高于价值就直接砍。** 一条要花两天查资料、只能拿三天流量的选题，不值得。

| 对标 | 数据 | 能学 | 能超 | 能持续 | 结论 |

## 我的差异化角度
（一句话：同类都在讲 X，我讲 Y，因为我手上有的东西是 Z）

- 时长：
- 平台：抖音 / 小红书 / 两端
- 成本：

## 风险提示
（可能踩的平台规则、可能引发误解的地方、需要核实的事实）

## 收尾

写完**停一次**，把选题卡给使用者看，确认后再进 `vflow-outline`。

不要在选题卡里写剧本。选题卡只回答"做不做"和"凭什么是我做"。
