# Vflow 的阶段边界（2026-10-23）

目的：**Vflow 独立自足，不依赖任何外部 skill 也能跑完整条流水线。** 环境里另装了更细的专项能力时，可以在指定节点做二次深检。两者不抢触发、不重复造轮子。

## 一、三条硬标准

| | Vflow 各阶段 | 通用分析工具 |
|---|---|---|
| **产物** | **必须落文件**到 `projects/<slug>/NN-xx.md`。不落文件等于没做完 | 只出分析和建议，不落项目文件 |
| **语境** | 只在"做一条内容"时触发（选题→复盘七阶段内） | 通用工具：商业诊断、概念拆解、决策跟踪、学习、知识库……内容只是其中一块 |
| **深度** | 够用即可的**闸口**——过关就往下走 | 可调用的**深挖**——想要逐句、想要多角度时用 |

一句话：**Vflow 是流水线，外部工具是外脑。** 流水线自己能跑通；遇到需要深挖的单个点，临时请外脑。

## 二、节点边界

每条内容都过 Vflow 版。下面这些情况才值得再跑一遍更细的专项能力：

| 阶段 | 值得多跑一遍的情况 |
|---|---|
| 选题 | 只想找对标、不想开项目；或要深挖观众动机 |
| 剧本 | 要逐句找共鸣断点 |
| 包装 | 角度还没定，要先开发主线 |
| 检查 | 高风险内容要逐句过：功效、数据承诺、同行提及；或平台提示异常需复查 |

成片阶段没有对等物。白板动画、章节导航这类属于**可选的成片增强**，可以作为 produce 阶段的路线补充，不是方法论的一部分。

## 三、一条原则

**Vflow 永远保持"零依赖可跑"。** 外部能力只作为可选增强存在，不能变成前置条件。这是 Vflow 能开源分发的底线——装了的人多一层能力，没装的人一个字都不缺。
